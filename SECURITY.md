# Security

Please do not report security problems in public issues.

Use [GitHub private vulnerability reporting](https://github.com/utibeabasi6/ukc-runner-controller/security/advisories/new) instead.
Include the steps to reproduce the problem and the version that you use.

You can expect a first response within one week.

## Scope

These parts are especially sensitive:

- The GitHub App private key and the tokens that the controller handles.
- The JIT runner configs that the controller passes to instances.
- The dashboard, which shows repository and workflow names.
